Jev 1.14, Jev 1.13 and three other System One models vs. people on seven decision-making tests

Classic problems from behavioural economics. Each row says what was asked and which answer is counted; some rows count the correct answer, others the typical human error. Left, asked with no instruction; right, with this instruction added first: “Answer the way a typical human participant in a psychology or economics experiment would actually answer — not the textbook-correct answer, and not an idealised one. Give the response the average person would give.” The tick is people; each mark is a model's probability on that answer, or its expected share.

Each model: mean of the probability distributions returned over 10 repeats. Models run 12–13 Oct 2026, except Jev 1.14 on 14 Oct 2026. Allais and Holt–Laury items re-asked 17 Oct 2026. Jev 1.14 was called through TypeSafe's API directly, the rest through OpenRouter. Human results: published studies or meta-analyses, listed in docs/BENCHMARKS.md.
