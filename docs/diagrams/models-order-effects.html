Option order · five models

How much five System One models' answers change when the options are shuffled

Each item was asked 10 times. Multiple-choice options were put in a new random order every time; Likert and yes/no items were left as they were, so they show how much the answers move with nothing changed. The gap between the two is the order effect. 0 means identical distributions, 1 no overlap.

Mean distance over all pairs of the 10 repeats, per item and prompt, on the 584 item-and-prompt cells (117 items) all five runs share; the follow-up items are left out, as for H6. GPT-6 Luna Decisions' floor is 0 because it returns the identical distribution on every repeat when nothing is shuffled. Models run 12–13 Oct 2026, except Jev 1.14 on 14 Oct 2026. Jev 1.14 was called through TypeSafe's API directly, the rest through OpenRouter.
