How much four System One models' answers change when the options are shuffled

Each item was asked 10 times. Multiple-choice options were put in a new random order every time; Likert and yes/no items were left as they were, so they show how much the answers move with nothing changed. The gap between the two is the order effect. 0 means identical distributions, 1 no overlap.

Mean distance over all pairs of the 10 repeats, per item and prompt, on the 710 item-and-prompt cells (147 items) all four runs share. Clef varies slightly less with shuffled options than without, so it shows no order effect beyond its repeat-to-repeat noise. GPT-6 Luna Decisions' floor is 0 because it returns the identical distribution on every repeat when nothing is shuffled. All models run 12–13 Oct 2026.
