Method

How each test item is run and scored

Each item is asked under four prompts: no instruction, ‘answer like a typical person’, ‘answer like a rational agent’ and an antisocial persona. Each model is asked every item ten times under each prompt. A System One model returns a probability for every possible answer on each call, and the ten distributions are averaged. A chat model returns one answer per call, and the ten answers are counted. Either way the result is one distribution per item and prompt, compared with the published human result for that test.

Costs are for the same 4,680 questions on 18 Sep 2026 (117 items × 4 prompts × 10): Jev 1.13 $0.09, Claude Sonnet 5 $2.74. The battery has 147 items since 30 follow-up items were added.
