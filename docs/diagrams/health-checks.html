Three problems found by the per-model error checks, and what was done

For each model the comparison counts errors, refusals, replies that could not be matched to an answer, and items left with no usable answer (results/comparison/health.csv). A reply that arrives but cannot be used is not a network error, so nothing would flag it without these counts. Two of the three problems were bugs in this repository.

results/comparison/health.csv. Models run 12–13 Oct 2026, except Drex 1.5 and Drex 2.0 on 15 Oct 2026. The truncated Haiku run was discarded, not mixed in.
