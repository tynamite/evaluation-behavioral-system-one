Framing effect · eight System One models

Size of the framing effect by model, in the disease problem

The same choice between a sure and a risky programme against a disease, worded once as lives saved and once as lives lost. People pick the sure option 72% of the time in the gain wording and 22% in the loss wording, a 50-point swing. Each row is a model's swing in points; below zero, it picks the sure option more often in the loss wording, the reverse of people.

The chart holds eight rows, so the rest are given here, with no instruction and as a typical person: Claude Sonnet 5.5 20 and 100; Claude Haiku 5.5 0 and 90; Decider v1.1 27B 3 and 21; Mercury Decide -0 and 18. Human rates: Tversky & Kahneman (1981). All models run 12–13 Oct 2026.
